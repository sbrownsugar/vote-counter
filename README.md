# เวทีนับโหวต

เว็บนับผลโหวตสำหรับงานออกบูธ — คนคุมกดรับโหวตจากหน้าหนึ่ง อีกหน้าขึ้นกราฟแท่งบนจอที่ต่อ HDMI แบบเรียลไทม์

ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์ และ**ใช้งานได้แม้ไม่มีอินเทอร์เน็ต**

## วิธีใช้ตอนออกบูธ

1. ต่อ HDMI แล้วตั้ง Windows เป็นโหมด **"ขยาย" (Extend)** — กด `Win` + `P`
2. เปิดเว็บบนโน้ตบุ๊ก กดปุ่ม **"เปิดจอแสดงผล ↗"** จะมีหน้าต่างใหม่เด้งมา
3. ลากหน้าต่างใหม่ไปไว้ที่จอ HDMI แล้วกด `F11` ให้เต็มจอ
4. คุมจากหน้าต่างเดิมบนโน้ตบุ๊ก กดปุ่มไหน กราฟบนจอใหญ่ขยับทันที

### หรือใช้หน้าต่างเดียวก็ได้

กดปุ่ม **"โหมดเต็มจอ"** จะมี **แถบคุมปักอยู่ล่างจอ** ให้เลย — แต่ละคนมีปุ่ม `−` กับ `+`
และมีช่อง **"ครั้งละ"** กำหนดว่ากดทีนึงเปลี่ยนกี่แต้ม (ตั้ง 25 ไว้ กด + ทีเดียวได้ 25 โหวต)
จะใช้ปุ่มลัดเลข `1`–`9` บนคีย์บอร์ดควบคู่ไปด้วยก็ได้

## ความสามารถ

- **หมวด (ไว้แบ่งสี)** — แบ่งเป็นหมวดได้ เช่น เต้น / ร้องเพลง (สูงสุด 6 หมวด รวม 24 คน)
  แต่ละหมวดมีสีประจำตัว คนในหมวดเดียวกันใช้สีนั้นไล่จากเข้มไปอ่อน มีป้ายบอกสีอยู่ข้างชื่องาน
- **อันดับนับรวมทุกหมวด** — กราฟเป็นกองเดียว **มีที่ 1 กับมงกุฎแค่ทีมเดียวทั้งงาน** เพราะรางวัลมีชุดเดียว
- **ชื่องานคลิกแก้ได้เลย** — คลิกที่ชื่อบนจอแล้วพิมพ์ทับ กด Enter
- **ใส่คะแนนได้ 3 แบบ**
  - ปุ่มด่วน `+1` `+5` `+10`
  - ช่อง "ใส่จำนวนเอง" — **บวกเพิ่ม**ตามที่พิมพ์ เช่น ซื้อทีเดียว 250 โหวต พิมพ์ `250` กด Enter (ใส่เลขติดลบเพื่อหักคืนได้)
  - **พิมพ์ทับเลขคะแนนใหญ่ๆ บนการ์ดได้เลย** — ตั้งเป็นเลขนั้นตรงๆ เหมาะกับตอนแก้ที่กรอกผิด หรือกรอกยอดที่นับจากกระดาษมาก่อน
- **กราฟแท่ง** เลือกแนวตั้งหรือแนวนอนได้ สลับอันดับแบบมีอนิเมชันเลื่อน
- **เลิกทำได้ย้อนหลัง 300 ครั้ง** กดผิดไม่ต้องตกใจ
- **บันทึกอัตโนมัติ** ปิดเว็บหรือไฟดับแล้วเปิดใหม่ คะแนนยังอยู่
- **ตารางผล + ปุ่มคัดลอก** เอาไปประกาศผลได้เลย

## ปุ่มลัด

| ปุ่ม | ทำอะไร |
|---|---|
| `1`–`9` | เพิ่ม 1 โหวต (นับเรียงจากหมวดแรกลงมา) |
| `Shift` + เลข | เพิ่ม 5 โหวต |
| `Ctrl` + `Z` | เลิกทำ |
| `F` | เข้า/ออกโหมดเต็มจอ |
| `Esc` | ออกจากโหมดเต็มจอ |

ปุ่มลัดใช้ได้ทั้งตอนแป้นพิมพ์เป็นภาษาไทยและอังกฤษ

## หมายเหตุทางเทคนิค

- สองหน้าต่างคุยกันผ่าน `postMessage` เป็นหลัก และมี `BroadcastChannel` กับ `storage` event สำรอง จึงทำงานได้ทั้งตอนเปิดจากไฟล์ในเครื่องและตอนเปิดผ่านเว็บ
- คะแนนเก็บใน `localStorage` ของเบราว์เซอร์ ไม่ได้ส่งออกไปไหน
- สีทุกเฉดผ่านการวัดคอนทราสต์แล้วว่า ≥ 3.3:1 บนพื้นเข้ม และชุดสีประจำหมวดผ่านการตรวจตาบอดสี
- สีผูกกับลำดับที่ตั้งไว้ ไม่ใช่อันดับคะแนน แท่งจึงไม่เปลี่ยนสีตอนแซงกัน
